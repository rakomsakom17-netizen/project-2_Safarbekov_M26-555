# Primitive DB

Учебная файловая база данных.

## Управление таблицами

База данных поддерживает работу в интерактивном терминальном режиме. Для запуска используйте команду:
```bash
database
Доступные команды
create_table <имя_таблицы> <столбец1:тип> ... — создание таблицы.
Допустимые типы данных: int, str, bool.
Столбец ID:int создается автоматически в начале, если не был передан пользователем.
list_tables — вывод списка всех созданных таблиц.
drop_table <имя_таблицы> — удаление существующей таблицы.
help — вывод справочной информации.
exit — завершение работы.
